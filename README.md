# RideSync

A Flutter app where a group of motorcyclists share their live location during a ride, see each other on a map, and follow a shared route to a destination.

## Versions

Flutter 3.47.6 and Dart 3.13.5. Check yours with:

```
flutter --version
```

## Run the app

```
flutter pub get
flutter run
```

Run `flutter pub get` again after every `git pull`.

Check your code:

```
dart format .
flutter analyze
flutter test
```
